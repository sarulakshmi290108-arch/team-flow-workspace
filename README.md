# Team Flow – Team Collaboration Workspace

## Project Description
Team Flow is a simple and professional team collaboration workspace developed using HTML and CSS.

## Features
- Top navigation bar with workspace branding and search.
- Left sidebar with workspace navigation.
- Main dashboard with project information.
- Three task summary cards.
- Right sidebar displaying team members and recent activity.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox

## Layout
The project uses nested Flexbox layouts to organise the navigation bar, sidebars, and main dashboard content.
